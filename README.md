# doc-proxmox

Documentation et tutoriels autour de Proxmox :
- PVE — Proxmox Virtual Environment
- PBS — Proxmox Backup Server
- PDM — Proxmox Datacenter Manager

Ce dépôt regroupe des notes, guides pratiques, procédures et retours d’expérience pour aider à installer, configurer, administrer et dépanner un environnement Proxmox.

---

## Objectif du projet

L’objectif de ce dépôt est de centraliser une documentation claire, structurée et facilement réutilisable sur l’écosystème Proxmox.

Tu y trouveras par exemple :

- des guides d’installation
- des tutoriels pas à pas
- des bonnes pratiques d’administration
- des procédures de sauvegarde et de restauration
- des astuces de configuration
- des notes de dépannage et de résolution d’incidents

---

## Contenu

Ce dépôt peut contenir, selon les sections, des documents sur :

### Proxmox VE
- installation de l’hyperviseur
- création et gestion de VM
- gestion des containers LXC
- réseau, stockage, snapshots, templates
- cluster, haute disponibilité, réplication

### Proxmox Backup Server
- installation et configuration initiale
- sauvegardes de VM / containers
- politique de rétention
- restauration de données
- intégration avec Proxmox VE

### Proxmox Datacenter Manager
- prise en main
- supervision centralisée
- gestion multi-environnements
- administration simplifiée des datacenters

---

## À qui s’adresse ce dépôt ?

Ce dépôt s’adresse à toute personne qui souhaite :

- découvrir Proxmox
- monter un lab de virtualisation
- administrer un serveur Proxmox en production
- mettre en place une stratégie de sauvegarde
- documenter ses propres procédures d’exploitation

## Démarrer

Pour parcourir la documentation :

1. ouvre la section souhaitée
2. lis les guides dans l’ordre recommandé
3. applique les procédures selon ton besoin
4. adapte les exemples à ton infrastructure
